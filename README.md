# Website SDIT ADZKIA

Website statis untuk GitHub Pages.

## Publikasi
1. Buat repository GitHub, misalnya `sdit-adzkia`.
2. Unggah seluruh isi folder ini (file `index.html` dan folder `assets`).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi. GitHub akan menampilkan alamat website.
